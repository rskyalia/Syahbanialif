# Project Images

Place your project thumbnail images in this directory.

## Required Images

Based on the current projects data, you need:

1. `placeholder-1.jpg` - Portfolio Website V2
2. `placeholder-2.jpg` - E-Commerce Dashboard
3. `placeholder-3.jpg` - Mobile App UI Design
4. `placeholder-4.jpg` - Brand Identity Design
5. `placeholder-5.jpg` - AI Content Generator
6. `placeholder-6.jpg` - School Event Poster Series

## Recommended Specifications

- **Format**: JPG, PNG, or WebP
- **Aspect Ratio**: 16:10 (e.g., 1600x1000px)
- **Max File Size**: 500KB per image (optimize for web)
- **Quality**: High quality but compressed

## Usage

The component will automatically show a gradient placeholder with the project's first letter if the image is not found. Replace these placeholders with actual project screenshots when available.

## Example File Names

```
placeholder-1.jpg
placeholder-2.jpg
placeholder-3.jpg
...
```

Or use actual project images:
```
portfolio-v2-hero.jpg
ecommerce-dashboard.png
mobile-app-ui.jpg
...
```

Update the image paths in `/data/projects.js` accordingly.
